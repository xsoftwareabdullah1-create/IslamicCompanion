# Contributing to IslamicCompanion

Thank you for your interest in improving IslamicCompanion. Contributions of all sizes are welcome, including documentation improvements, accessibility fixes, bug reports, and new features.

## Before you start

- Read the project README and any instructions in the area you plan to change.
- Check existing issues and pull requests to avoid duplicating work.
- For a significant feature or behavior change, open an issue first to discuss the approach.
- Keep changes focused and explain the problem they solve.

## Development workflow

1. Fork the repository.
2. Create a branch from `main` with a descriptive name, such as `docs/improve-setup-guide` or `fix/navigation-labels`.
3. Make your changes in small, reviewable commits.
4. Run the checks relevant to your changes. If the project does not yet provide automated checks, say so in your pull request.
5. Review your diff and remove unrelated changes.
6. Push your branch and open a pull request against `main`.

## Pull request checklist

- [ ] The purpose and user-visible impact are explained.
- [ ] Changes are limited to the stated scope.
- [ ] Documentation is updated where needed.
- [ ] Relevant tests or checks have been run, and their results are reported.
- [ ] No passwords, API keys, tokens, or other secrets are included.
- [ ] New content is respectful, accurate, and appropriately sourced.

## Reporting bugs

When opening an issue, include:

- A clear, descriptive title.
- Steps to reproduce the problem.
- What you expected to happen and what happened instead.
- Relevant device, browser, or environment details.
- Screenshots or logs when they help explain the issue (remove personal information and secrets first).

## Documentation and Islamic content

Please use clear language and cite reliable sources for religious references. Distinguish sourced religious text from commentary, preserve the context of quotations, and flag differences of scholarly interpretation rather than presenting one view as universally agreed. Do not add an unverified Qur'an or hadith quotation.

## Code quality and accessibility

- Follow the conventions already used in the affected part of the project.
- Prefer simple, maintainable solutions over unnecessary dependencies.
- Use meaningful names and explain non-obvious decisions.
- Make interactive elements usable with a keyboard and assistive technologies.
- Check responsive layouts and readable contrast when changing the interface.

## Community expectations

Be respectful, constructive, and welcoming. Focus feedback on the work, assume good intent, and help keep discussions useful for contributors with different experience levels.

Thank you for helping make IslamicCompanion better.
